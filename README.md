# Linux / Shell Lab

A hands-on laboratory for developing practical Linux and shell skills for DevOps.

This repository documents practical exercises, experiments, command-line investigations, and troubleshooting work completed while building Linux administration and shell automation fundamentals.

## Focus Areas

- Linux filesystem and metadata inspection
- File discovery and permissions
- Shell pipelines and text processing
- Log analysis
- Input/output redirection
- Process and system inspection
- Networking fundamentals and troubleshooting
- Shell scripting and practical automation

## Repository Structure

| Path | Purpose |
|---|---|
| `docs/learning-notes/` | Concepts, explanations, and learning notes |
| `docs/command-reference/` | Quick reference for commands and syntax |

## Working Principles

This is a practice repository, not a collection of copied tutorials.

Each topic is learned through practical exercises, experimentation, and small investigations. Documentation should reflect work actually completed, with results and limitations recorded honestly.
