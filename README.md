# Linux / Shell Lab

A hands-on laboratory for developing practical Linux and shell skills for DevOps.

This repository contains exercises, experiments, scripts, troubleshooting notes,
and practical challenges completed while building Linux administration and shell
automation fundamentals.

## Focus

- Linux filesystem and metadata
- File discovery and permissions
- Shell pipelines
- Text processing
- Log analysis
- Input/output redirection
- Shell scripting
- Process and system inspection
- Troubleshooting
- Practical automation

## Philosophy

This is a practice repository, not a collection of copied tutorials.

Each topic is learned by solving practical problems, experimenting with commands,
and building small tools.
